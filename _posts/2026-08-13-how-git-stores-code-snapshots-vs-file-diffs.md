Imagine taking a full polaroid photo album of your project. This is how Git actually stores code, by taking snapshots of your entire project at a point in time, rather than just saving the changes made, a commit — a snapshot of your project. Git stores these snapshots in a repository, a central location where all the snapshots are kept, allowing you to easily switch between different versions of your project. You now understand that Git stores code as snapshots, not file diffs.
